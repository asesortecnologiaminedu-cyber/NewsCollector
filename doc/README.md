# NewsCollector Documentation (Diataxis)

This folder contains project documentation organized using the Diataxis framework.

- Tutorial: `doc/tutorials/create-your-first-newsletter.md`
- How-to: `doc/how-to/configure-ai-post-processing.md`
- Reference: `doc/reference/newscollector-reference.md`
- Explanation: `doc/explanation/newscollector-architecture.md`

## Who This Is For

- Python developers integrating NewsCollector into scripts or automation
- Developers running NewsCollector from the CLI
- Maintainers extending scraping, clustering, and AI post-processing behavior

## Scope

Included:

- End-to-end usage for the current codebase
- AI post-processing prompt and model configuration
- API and CLI behavior, arguments, and return values
- High-level architecture and design trade-offs

Excluded:

- Packaging and release automation
- Deployment in container/orchestration platforms
- Frontend customization of newsletter CSS and assets
